# GFS-A002 — 적 스폰 및 웨이브 관리 시스템

## 과제 개요

**적의 생성, 사망 및 웨이브 진행 상태를 관리하는 시스템을 구현하는 과제.**

Unity 3D 환경에서 플레이어가 웨이브를 시작하면 여러 적이 생성되고, 모든 적을 처치하면 웨이브가 완료되는 구조를 구현한다.

개별 적의 상태 변화가 웨이브 관리 시스템과 UI에 반영되는 과정을 통해 여러 클래스 간 데이터 흐름과 통신 구조를 학습한다.

### 개발 환경

- **Engine:** Unity 3D
- **Language:** C#
- **Training Mode:** MODE A — 독립 설계 및 구현

## 학습 목표

- **클래스 책임 분리:** 적, 웨이브, UI 등 시스템별 역할과 책임 구분
- **데이터 소유권:** 체력, 생존 적 수, 웨이브 상태의 관리 주체 결정
- **클래스 간 통신:** 여러 객체 사이의 호출 관계와 의존성 설계
- **이벤트 기반 처리:** 적 사망 및 상태 변경을 다른 시스템에 전달
- **객체 생명주기:** 적 생성부터 사망 및 제거까지 관리
- **상태 관리:** 웨이브의 시작, 진행, 완료 조건 처리

## 필수 구현 요구사항

### 1. 적 생성
- Space 키 입력으로 웨이브 시작
- 웨이브 시작 시 지정된 위치에 적 3명 생성
- 웨이브 진행 중 중복 시작 방지

### 2. 적 체력 및 사망
- 적 개별 체력 관리
- 마우스 클릭으로 적에게 피해 적용
- 체력이 0 이하일 때 사망 처리 및 오브젝트 제거
- 적 사망 사실을 다른 시스템에 전달

### 3. 웨이브 관리
- 현재 생존한 적의 수 관리
- 적 사망 시 생존 수 갱신
- 모든 적이 사망하면 웨이브 완료
- 완료 후 다음 웨이브 시작 가능

### 4. UI
- 현재 생존한 적의 수 표시
- 웨이브 진행 및 완료 상태 표시
- 데이터 변경 시 UI 갱신

## 구현 제외 범위

- 적 AI 및 이동
- 공격 애니메이션
- 여러 종류의 적과 웨이브
- 오브젝트 풀링
- 멀티플레이 및 네트워크
- 데이터 저장 및 불러오기
