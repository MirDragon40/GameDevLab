# GFS-A003 — 게임 상태 및 라운드 타이머 관리

## 과제 개요

게임의 진행 상태와 라운드 타이머를 관리하는 시스템을 구현하는 과제.

대기, 진행, 일시정지, 종료 상태를 정의하고 현재 게임 상태에 따라 타이머와 사용자 입력을 제어한다.

### 개발 환경

- **Engine:** Unity 3D
- **Language:** C#
- **Training Mode:** MODE A — 독립 설계 및 구현

## 학습 목표

- 게임 상태 및 상태 전이 설계
- 클래스별 책임 분리와 데이터 소유권
- 클래스 간 통신 및 의존성 설계
- 이벤트 기반 UI 갱신
- 타이머 및 상태 관리
- 예외 상황과 중복 입력 처리

## 필수 구현 요구사항

### 1. 게임 상태 관리
- Idle, Playing, Paused, Ended 상태 관리
- 상태별 입력 및 실행 조건 검증
- 유효하지 않은 상태 전이 방지

### 2. 라운드 타이머
- 30초 라운드 구현
- Enter 키 입력으로 시작
- 진행 상태에서 시간 감소
- 시간 종료 시 게임 종료 처리

### 3. 일시정지 및 재개
- P 키 입력으로 일시정지 및 재개
- 일시정지 중 타이머 정지
- 상태에 따른 입력 제한

### 4. 게임 재시작
- 종료 상태에서 R 키로 재시작
- 라운드 시간 및 게임 상태 초기화

### 5. UI
- 현재 게임 상태 표시
- 남은 시간 표시
- 상태 및 시간 변경에 따른 UI 갱신

## 구현 제외 범위

- 플레이어 이동 및 전투
- 점수 및 보상 시스템
- 전체 씬의 물리적 일시정지
- 애니메이션 및 사운드
- 데이터 저장 및 불러오기
- 멀티플레이 및 네트워크
