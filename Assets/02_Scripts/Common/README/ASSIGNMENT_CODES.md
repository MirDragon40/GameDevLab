# 과제 코드명 정리

Gameplay Full-Stack Practice에서 사용하는 과제 코드와 학습 방식 정리.

## 코드 읽는 법

`GFS-A001`을 예로 들면 다음처럼 나눠 읽을 수 있다.

| 구분 | 의미 |
| --- | --- |
| GFS | Gameplay Full-Stack Practice의 약칭 |
| A | 학습 방식. A는 직접 설계하고 구현하는 과제 |
| 001 | 과제 번호 |

GFS와 숫자 부분은 과정 이름과 코드 형식을 기준으로 풀어 쓴 것이다. 번호를 모드별로 매길지, 전체 과제 순서대로 매길지는 아직 정하지 않았다.

## 학습 방식

알파벳은 난이도가 아니라 연습하는 방식을 나타낸다.

### A 직접 설계하고 구현하기

요구사항을 보고 필요한 클래스와 역할을 나눈 뒤 직접 코드를 작성한다. 막히는 부분은 AI에게 힌트를 받고, 작성한 코드는 리뷰를 받는다.

요구사항 분석 → 책임 분리 → 클래스 간 통신 설계 → 구현 → 테스트 순서로 진행한다.

### B AI가 작성한 코드 분석하기

주어진 코드가 어떻게 동작하는지 읽고 설명하는 연습이다. 데이터가 어디에 있고 어떤 순서로 전달되는지 살펴보며, 잘못된 부분이나 개선할 점을 직접 찾아본다. AI에게는 분석이 맞는지 피드백을 받는다.

### C AI와 함께 만들고 개선하기

만들 기능과 조건을 먼저 정하고, AI에게 맡길 작업을 나눈다. 나온 결과는 직접 읽고 테스트하면서 수정한다. 무엇을 맡길지 판단하고, 결과가 요구사항에 맞는지 확인하는 연습이다.
